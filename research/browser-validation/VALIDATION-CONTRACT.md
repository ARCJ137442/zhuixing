# 冻结单 HTML 浏览器验收合同

## 前提与范围

1. 使用已获准的隔离测试环境；记录已安装浏览器和工具版本，不改变安全设置或使用个人浏览器资料。
2. 固定被测 HTML SHA256，不将历史报告的SHA默认为当前版本。将单文件复制到独立测试目录，临时 HTTP 仅绑定127.0.0.1，只提供此文件。记录实际浏览器版本、OS、viewport、缩放与字体可用性。使用独立测试profile，不清理或覆盖用户原profile。
3. Chromium/Firefox/WebKit分别运行；不存在的浏览器明确skip，不以Chromium通过代替其它引擎。不要对已知抱缺陷悄悄修改映射后宣称旧版本通过。
4. 只经可见控件、键盘和标准输入操作。禁止直接修改应用变量、localStorage、DOM，或伪造composition事件作为真实输入法证据。纯模块/模拟测试另记。

## 有界用例与通过条件

- 启动：页面标题、版本、首屏、空态截图。记录任何控制台错误，不把截图存在当功能通过。
- 字符区别：分别输入“⿰亻报”“⿰亻包”“⿰扌包”“抱”，每次记录源文和呈现截图。不得因外形相似将亻表达式认成扌表达式；记录冻结版本的实际映射/字体回退状态。
- 保三形式：输入“⿰亻呆⿰亻⿱口木保”，确认显示与源文分离；切源码仍完整原串。选择整段，分别经按钮、启用后的快捷键、命令面板合到底，再一次undo恢复原串；每条路线从干净测试状态开始。
- 分层：对“⿰亻⿱口木”合一层后应“⿰亻呆”，再一层为“保”；逐笔undo恢复。混排前后文字不得变化。
- 选择与字素：实际鼠标拖选和Shift扩选；测试𰻝、保+VS、保+IVS、ZWJ/修饰符、ZWNJ/tag附着；不允许孤立代理项或修饰符迁移。存在无法用当前输入设备创建的用例则明确未验。
- 复制：通过真实Ctrl/Cmd+C与粘贴验证源IDS而非显示字符，不能仅读取DOM textContent代替系统剪贴板。保持测试源可恢复。
- 视图：source不自动收起；preview下beforeinput、键盘、菜单拆合和undo不得改源。允许显式确认的项目导航，并保持只读；取消/晚到请求不覆盖当前源。
- 导出：用实际点击触发项目和SVG下载，等待浏览器下载事件，检查所得文件。保的字体SVG包含保的text及原sourceIDS，portableOutlines=false；无完整字轮廓时不能假称纯outline可用。项目文件源串与版本元数据正确；旧格式导入保留源。
- 动效：默认开与手动关、系统reduced-motion、快速输入及切后台；稳定结果始终可用。只能将亲眼看到/采集到的效果写为观察结果，不以动画参数证明流畅度。
- IME：只有真实系统中文输入法候选/确认/取消才记通过。无输入法或自动化无法操控时记未验，提供人工步骤；dispatchEvent不补足此证据。

## 输出与停止条件

每例写 executed/pass/fail/blocked/skip、步骤、实际值、预期、截图路径、浏览器版本和sourcehash。失败保留原始截图、输入及下载文件；不覆盖失败证据。不做无界压力测试。

遇登录、URL策略、浏览器安全警告、系统权限或不可达回环，停止该路线并报告具体动作/目标/原因，不绕行。所有授权可达用例结束或明确阻断后，停止临时服务，交付矩阵及缺口，不自行发布修复。
