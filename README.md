# Structure Glyph Workbench

以 IDS 为真实源文本的离线汉字构形编辑器。暂用工作名，产品正式名称尚未决定。

## 开始使用

直接打开 app/index.html，无需构建或联网。当前为 0.2.1 本地版本：保留可逆源编辑，新增独立视图/编辑单位/设置系统、按需键盘提示和实验性光学字形引擎。

所有功能均应有纯键盘路径；动画和轮廓数据不能决定基本编辑功能是否可用。字体回退和实验性输出会明确标识，不冒充规范字形。

## 验证

    node scripts/test.mjs

14 套主程序测试与 38 项适配器检查在本地通过，无需安装依赖。真实浏览器、中文 IME、触屏、原生剪贴板/下载和视觉审美尚未验收。

文档再生成单独需要 markdown-it；字体资产再生成需要固定 Noto 字体和 fontTools。运行应用不依赖这些维护工具。
