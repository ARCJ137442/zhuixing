# 0.4.0 本地候选键盘验收矩阵

日期：2026-10-25（Asia/Shanghai）

本矩阵描述本地未发布 UI 候选。IDC/O 符/偏旁快捷键仅在 **live 行内编辑视图**、编辑器拥有焦点且没有 IME 组合时生效；源码视图与只读预览不接管这些键。按钮面板仍可通过 Tab/Shift+Tab 到达，使用 Enter/Space 插入。源码仍是唯一可编辑身份；IDC 快捷键写入同一 Unicode 字符并沿用正文撤销。

## 当前绑定与冲突

| 绑定 | 当前动作 | 冲突与影响 | 当前替代路径 | 状态 |
|---|---|---|---|---|
| Alt+← / → | 插入 ⿰ / ⿲ | Edge 将 Alt+←/→ 用作后退/前进；浏览器或系统可能先截走事件，导致导航而非插入 | 插入面板中点选 IDC 按钮；也可在设置关闭 Alt 候选 | 代码仅限 live；OS/浏览器交付 **NOT_RUN** |
| Alt+↑ / ↓ | 插入 ⿱ / ⿳ | Alt+方向在浏览器、窗口管理器与辅助功能中的行为随宿主变化；未完成设备矩阵 | 同上 | 代码映射 **PASS**；OS/浏览器冲突 **NOT_RUN** |
| Alt+字母 / Alt+减号（其余 13 项） | 插入对应包围、叠加或变换 IDC | Alt 可能触发浏览器菜单、网页访问键或系统菜单；物理键标签也受键盘布局影响 | 17 个 IDC SVG 按钮；可在设置关闭；浏览器支持 Keyboard Layout Map 时显示可见键帽 | 代码映射 **PASS**；布局与宿主冲突 **NOT_RUN** |
| Alt 单独按下，再按 IDC 候选键 | 打开光标旁 17 项候选，第二键插入 | Alt 本身及后续键仍可能被宿主截获；Alt HUD 是瞬时层 | IDC 插入面板 | 合成浏览器 **PASS**；真人按键 **NOT_RUN** |
| Alt+Shift，再按字母 | 打开本地 O 符键位图；多候选显示候选卡，不按码表顺序猜选 | 部分输入法把 Alt+Shift 用作 ASCII/输入模式切换；私人映射不应作为产品数据导出 | 搜索/选择常见偏旁面板；Escape 取消；设置可关闭 | 浏览器合成流程 **PASS**；真人输入法 **NOT_RUN** |
| Shift+F | 插入 扌 | Shift+字母可产生大写输入；输入法也可能把大写作为编码。设置可关闭 | 常见偏旁面板 | 当前浏览器合成 **PASS**；真人输入法 **NOT_RUN** |
| Shift+← / → | 保留原生文本扩选 | 用户曾建议 Shift+→ 插入 ⿰；该键已有扩选语义，抢占会破坏精确选区 | IDC 按钮或 Alt 候选 | 浏览器合成扩选 **PASS**；真人实体键 **NOT_RUN** |
| Ctrl+Shift+F | 交还宿主 | 可能由输入法或其他应用使用 | 常见偏旁面板 | 受控处理器 **PASS**；具体设备行为 **NOT_RUN** |
| Alt+[ / Alt+] | 选区拆字 / 合字 | 括号位置因布局不同；Alt 可能触发宿主菜单。不能用于缺失或多形式映射 | 画布旁拆字/合字按钮；不适用时保持禁用 | 受控处理器 **PASS**；实体布局 **NOT_RUN** |
| Tab / Shift+Tab，Enter / Space | 到达菜单按钮并插入 | 需确保焦点顺序和关闭返回路径 | 等价按钮保持可用 | IDC 面板的浏览器辅助树可见；完整真人键盘路径 **NOT_RUN** |

17 项 IDC 对照表在 docs/KEYBOARD.md。其中 Alt+←/→ 是明确的 Edge 冲突风险，因此不得描述为跨浏览器无冲突。用户提出的 Shift+→ = ⿰ 不采纳为默认键位，以免覆盖 Shift 扩选。

## 冲突时的建议路径

1. **无系统冲突路径（当前可用）**：聚焦“插入 IDC / 示例”按钮，Tab 到目标 SVG 按钮，再按 Enter/Space；鼠标与触控也可点选。
2. **当前快捷方式（可关闭，设备候选）**：只在 live 编辑器焦点内使用。Alt 候选、Alt+Shift O 符与 Shift+F 都过滤 IME 组合、键码 229、AltGraph、重复键与额外修饰键。
3. **后续可评审方案**：若真实 IME/浏览器冲突频繁，可将快捷键入口改为用户点击一次“IDC 键盘”后进入短暂选择态，再用方向键和 Enter 选择。选择态必须有明显标题、Esc 取消、焦点恢复、手机按钮等价路径；不得常驻劫持字母输入。该方案未实现。

## 本轮验证边界

- **PASS · 命令注册表**：全部 17 个 Alt IDC 映射、提示一致性、设置关闭、IME/229/AltGraph、重复键、额外修饰、编辑器焦点及 live/source/preview 视图边界。
- **PASS · 受控键盘处理器**：Alt IDC 插入、Alt 候选开启、O 符候选、Shift+F、Shift 扩选及 source 视图不派发快捷插入。该测试调用维护中的事件处理器，不经过操作系统键盘。
- **PASS · 浏览器自动化（合成）**：Alt+Q 插入 ⿸、Alt+Shift+F 显示 O 符候选并确认、Shift+F 插入 扌、Shift+← 扩选；结果用于检查页面交互与反馈，不代表真实设备会把按键交给页面。
- **NOT_RUN · 真人 Windows 输入法**：Rime/Weasel 组合中英文切换、Alt+Shift 与左右 Shift 变体。
- **NOT_RUN · 实体键盘/操作系统**：Alt 方向的 Edge 后退/前进、其他浏览器保留键、键盘布局与访问键冲突。
- **NOT_RUN · 跨浏览器和辅助技术**：Firefox/WebKit、读屏器、键盘焦点完整巡回。

检查失败时应先使用按钮路径并关闭对应快捷键，不应把未收到的键补成成功插入。所有测试状态都与全量 Unicode 覆盖门禁分开；字符覆盖报告仍为 dataCoverageComplete=false、releaseGate=blocked。
