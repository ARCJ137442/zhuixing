# 缀形 0.4.0

0.4.0 是在 0.3.1 源码基线上整合品牌、编辑界面与快捷输入的一次私有版本发布。冻结交付 HTML `0.4.0-rc.9` 是不同的历史构建，不是本版本的精确源码。

## 本版内容

- 采用已获用户确认的双色缀形 SVG 标志，并在应用中离线内嵌。
- 17 个 IDC 在插入面板、快捷候选和编辑区统一呈现为 SVG；当前不支持几何布局的 5 项继续明确标注。
- 默认折叠构形观察，拆字/合字成为编辑画布的一等动作；`Alt+[` 拆、`Alt+]` 合，精确源事务可撤销。
- IDC 按住 `Alt` 显示候选；`Alt+Shift` 打开 O 符键位图，单项直插，多候选经用户选择确认；保留 `Shift+F → 扌` 与 61 项可选偏旁。
- 支持逐字来源明确的 IDS 精确合字；字符有多个 IDS 时，合字可按当前选中的精确形式执行，反向拆字不猜选。

## 覆盖和验收边界

本次按维护者指示发布 UI/输入功能，不表示完整汉字覆盖已达成。固定 Unicode 17 审计枚举了 20,992 个 URO 字与 TGH 一级 3,500 字：当前严格唯一映射分别为 2,065 与 412；多形式与缺失情况见 [全量覆盖报告](../tests/full-coverage-tools/reports/full-coverage-latest.json)。全量审计的 `releaseGate` 仍为 blocked，缺失项未删除、未降低期望、未修改锁。

本地 HTTP 浏览器验收通过代表性路径，包括 17 个编辑区/菜单 SVG、一层拆 `衫` 并选中完整 IDS、拆合撤销、多 IDS 精确合字、O 符空格确认与桌面/手机布局。浏览器自动化按键不代替真人 IME/实体键盘验收。全字体码位、全量逐字渲染/导出、跨浏览器矩阵、读屏和系统快捷键冲突仍未验收。

私有 GitHub 仓库未新增软件开源许可证；`LICENSE-DECISION.md` 仍待维护者决定。第三方 IDS、Unicode 数据和 OFL 字体许可证沿用各自来源声明。
