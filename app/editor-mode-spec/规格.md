# 组字编辑器 0.2.0：统一编辑单位、视图与设置

状态：可实施行为规格与待执行验收，不是实现完成声明。2026-10-20。未修改活跃 index.html；0.1.6 字体回退先独立收尾。本规格默认值是本轮工程决定，不冒充用户已逐项裁决。

## 1. 两个独立轴

- editor.view：preview（只读预览）、live（行内编辑，默认）、source（源码编辑）。
- editor.unit：display-glyph（最终呈现字）、ids-grapheme（构型原字符簇，默认）。
- 只有 live 采用单位偏好。preview 没有编辑光标；source 始终源字符簇。单位选择仍可修改、导出和保存，控件旁短注“当前视图不使用；返回行内编辑后生效”，不可悄悄改写偏好。
- 默认保留最近明确的逐构型退格方向，并使箭头及 Delete 同样逐源字符；从 0.1.5 升级需一次说明“光标、前后删除现在共用构型单位；可选完整字单位”。不臆造旧版不存在的持久设置。
- 借鉴的是“阅读与编辑分离、行内编辑与源码分离”，不是 Obsidian 外观或快捷键。其官方说明中 Live Preview 聚焦格式内容时显示源语法，Source mode 显示全部源语法；本项目进一步引入独立编辑单位，故整字模式点击不自动进入内部。[Obsidian 官方 Views and editing mode](https://obsidian.md/help/edit-and-read)，2026-10-20 查阅。

## 2. 权威模型与单位

source 是唯一正文；selection 为有方向的 UTF-16 {anchor,focus}。所有 offset 都必须处于 grapheme 边界，不能切代理对、附着变体选择符、组合标记或 ZWJ 链。使用同一 GraphemeBoundary 服务；没有完整分段能力时明确降级，不承诺覆盖全部 Unicode。

边界表不得从“当前 DOM 有没有 atom”、动画是否结束或临时展开反推：由 source、解析结果、呈现资格及配置生成稳定 projection。display-glyph 中每个可呈现的完整顶层 IDS 根范围是一单位（嵌套整体一单位），普通文本是一 grapheme；Unicode 显示、SVG 与 0.1.6 字体回退都是相同单位。未完成或确实只能显示原文的结构保持源 grapheme，不能伪装成不可见整字。切换匹配显示导致无法渲染时可能改变边界，按下述切换契约处理。

ids-grapheme 表示源串的一个 grapheme，不是叶子子树，也不是一个 UTF-16 code unit。⿰⿱日月木 在末尾逐退为 ⿰⿱日月 → ⿰⿱日 → ⿰⿱ → ⿰ → 空；不会先删整个 ⿱日月。源单位下仅光标所在/选区触及的结构展开，其他结构可继续呈现。

## 3. 共用行为与六组合

六组合的逐项机器契约见 acceptance-matrix.json。以下规则与其一同构成验收标准。

### 行内编辑 × 最终呈现字

左右箭头跨前/后一完整单位；非空选区时无 Shift 向相应边收拢，不多走一步。Shift 固定 anchor 并逐单位移动 focus，反向选择保留方向。Backspace 删除前一单位，Delete 删除后一单位；有选区均仅删除精确所选范围，一次事务。文本边界删除无操作、不产生历史。点击字形左右半部定位其前/后边界，不展开内部；拖选/触摸选择按单位边界吸附并保留方向，必须在释放前看到将选中的范围，不能按删除时才扩选。提供“源码编辑”明确入口用于改一个部件，不能点击自动偷换单位。

### 行内编辑 × 构型原字符簇

左右、Shift、Backspace、Delete 使用相同源 grapheme 表。进入字形内部时原位展开源文，左移从末端进入、右移从首端进入；点击字形先展开，再以真实命中位置定位，无法精确映射时默认最近源边界并显示光标，不假造叶子几何映射。连续删除逐源字符，结构不完整立即保留源码。拖选允许部分 IDS，真实拆合不因此扩大选区。

### 源码编辑 × 任一偏好

所有 source 原样可见，不呈现 Unicode 替身/合成 atom。编辑按源 grapheme；单位偏好保留且无效。unicode.presentation 与动效偏好保留但暂不作用。autoConvert 即使保存为 true，在源码模式也暂停，标注“源码模式暂停自动真转换”，避免刚输入源码却被自动消失；回到 live 不追溯转换。显式选区拆/合仍可执行并记录正文历史。

### 只读预览 × 任一偏好

呈现最终结果和必要回退/未完成状态；contenteditable=false，无编辑插入点。左右及 Shift 交给浏览器阅读/选择行为，不伪装单位编辑。点击不展开为编辑，允许只读选择与复制，Tab 仅遍历真实操作控件。Backspace/Delete、粘贴、剪切删除、拖放、输入与历史撤销均不得改变 source；应用“拆/合/撤销/重做”按钮禁用并解释“切换到编辑视图”。不能仅依靠隐藏按钮，事务入口也检查只读。预览中的复制按最终选中对象对应原始 source 输出；字形内部无源命中则映射整对象，不按视觉 Unicode 偷改剪贴板。

### 修饰键、焦点、Tab、IME、历史和复制

- Ctrl/Cmd+C/V/X/Z、Ctrl+Y、平台词/行导航保留平台约定，仅编辑器上下文执行应用等价命令。Windows/Linux Ctrl+左右/删除、macOS Option+左右/删除：先求平台词范围，在 display-glyph 中向运动方向越过完整单位，不落入 IDS 内；源单位/源码按平台词范围但不切 grapheme。非空选区仍精确操作。Cmd+左右/Home/End 保留平台行边界；禁止沿用 Ctrl+Backspace 独有整组删除特例。跨平台词边界由适配器定义和实机验收，不宣称浏览器一致。
- 不注册页面级/浏览器级快捷键拦截；配置搜索框、设置控件、文档面板及其他输入域不使用编辑命令。AltGraph、IME、无效组合、无修改、重复触发保护沿用现有选区命令契约；系统占用快捷键无法保证收到事件。等价按钮始终存在。只对确实处理的可取消事件 preventDefault。
- Tab/Shift+Tab 始终焦点导航，不插制表符、不吞走出编辑器的机会；取消每字 atom 的独立 Tab 停靠，编辑画布一个入口，其余操作可正常遍历。字形细节通过单位切换/源码入口获得，Enter 不成为隐式改单位开关。
- IME composing 期间浏览器拥有组合范围，不运行字形投影重建、单位吸附、删除接管或自动真转换。组合落在 display 单位边界开始；原有选区作为替换范围。结束后单次提交源编辑，再按现有可撤销自动合字规则处理（仅 live 且开关开）。过期会话不得提交。视图/单位切换或设置导入遇 composing 时保留待应用请求并提示“输入法确认后应用”，可取消，不强行结束候选；最后一次用户请求胜出，显式取消撤掉请求。
- 正文 undo/redo 恢复 source 与其有方向源选区，不切换用户配置；投影/动效/视图切换不加正文历史。自动合字与用户输入仍分两事务，第一次撤销恢复完整 IDS。
- Copy 始终复制所选 source（真实转换过则自然是 Unicode），不是 innerText/画面替身。剪切只在可编辑模式且剪贴板写入成功后删除精确范围。单独“复制呈现字”若未来增加必须独立命名，不能静默改变默认复制。

### 切换保真，不偷偷扩大破坏范围

视图切换、单位切换、匹配显示变化：保存源选区、滚动与焦点归属，取消旧动效/定时收起，提交一次配置事务后重投影。source 不变，不重播历史动效。进入 preview 保存编辑 selection，返回恢复。

当切到 display-glyph 时，已有折叠光标在新单位内部，吸附最近外边界（等距取后），短反馈“已按整字单位定位”。已有非空部分 IDS 选区必须原样保留并临时源文显示，状态提示“保留原有源选区”；删除/替换/复制只针对原范围，绝不静默向外扩展。下一次无 Shift 左右收拢到相应整体外边界；下一次 Shift 导航仍固定原 anchor（临时源选区例外）直到用户收拢或重新选择。这是跨模式继承的显式例外，不允许新的鼠标选择偷偷产生部分整字范围。undo 恢复内部选区采用同一例外。

## 5. 导入导出与存储

配置格式独立：kind="structure-glyph.settings"，schemaVersion=1，settings 为上述扁平 key/value 对象；文件名 structure-glyph-settings-v1.json。项目继续现有 formatVersion/source 契约，文件名和按钮明确“项目（正文）”与“设置（偏好）”。配置 JSON 不得包含 source、selection、history、草稿、文件路径、URL、密码、令牌、字体二进制或诊断记录。导出仅按 schema 白名单构造，不直接 stringify localStorage/app state。

导入流程：限定 64 KiB UTF-8 → 严格 JSON 解析（拒绝重复 key、危险 __proto__/constructor/prototype，拒绝数组/错误根类型/非 plain object；JSON 根与 settings 原型必须为 Object.prototype 或 null，程序入口也执行同一检查）→ 检查 kind/version → 纯函数逐版本迁移 → 全量类型、枚举、范围校验 → 差异预览 → 用户应用 → 一次 commit。拒绝字符串布尔/数值，不自动 coercion。导出的完整配置按“替换全部设置”导入；缺失已知 key 使用该 schema 的默认值并在差异里列出，不隐式保留当前随机值。未知 key 拒绝整份文件并列 key，避免悄悄丢失新版本配置；未知未来版本同样拒绝，不试猜。版本 1 无历史设置文件可迁移，不能把旧项目 JSON 当设置。后续迁移明确 old→new，保持原文件不变，失败零改动。

无效、取消、读入过期均不改变任何设置/正文。读入 A 慢、B 快时只有最新导入有资格显示/提交；读入期间用户改设置或新开导入使旧 preview 失效，需重新比较，不能覆盖新操作。composing 时应用延后见上文。

导入开启 autoConvert 只改变后续 live 新输入的资格：导入当刻、重投影、视图切换、恢复偏好、撤销配置都不得扫描或改现有 source。差异确认中突出“自动真转换：开，之后新输入会改变原文”，不与显示匹配混为一谈。

独立 settings history（会话内上限 50，具名常量）支持撤销/重做设置；设置面板按钮作用配置，正文 Ctrl/Cmd+Z 仍作用正文，配置导入/重置是一条配置事务。提供单项恢复默认、全部恢复默认与取消；整体重置先给差异，不删除项目/正文/草稿。不把恢复出厂直接清空 localStorage。

持久化使用独立 key structure-glyph.settings.v1。单次提交一份完整快照；写失败保留会话有效设置并提示“本次有效，未能保存”，不冒充持久成功；重开只加载最后成功快照。多页监听 storage 只提示外部更新，不自动覆盖当前设置；明确选择重新加载后才应用。不是跨设备同步。验证存储读取/写入失败、坏文件恢复与跨页冲突。

## 6. 设置 UI 与搜索

更多菜单保留简短项目动作，统一“设置”入口打开可搜索面板；顶层可见当前视图，单位在 live 附近可快速选择并链接对应设置。无需全屏复制 Obsidian。三个视图名称固定，激活态表示当前值；只读徽标持续可见，弱化版本号保留。

搜索只过滤设置条目，匹配名称、说明、key、中文/英文 aliases（例如 光标/退格/删除/粒度、预览/阅读/源码、动画/动效、Unicode/合字/自动转换）。空查询显示分类；无结果显示清除入口。结果列展示当前值、适用性与命中说明，选择结果将焦点送对应控件；Escape 清查询优先，然后关闭面板并回原入口。焦点内键盘导航不触发编辑器命令。

搜索不隐藏只读状态、source 未保存/保存失败、导入错误/待应用差异、自动真转换警告或系统 reduced-motion 原因。危险语义留在对应开关附近，即使折叠/过滤也可发现。窄屏下搜索、导入、导出、重置与关闭保留可触点击区，禁用项有原因且可读屏访问。只用实际状态反馈成功，配置改动不播放正文合成动画。

## 7. 实现边界、验收与依据

建议职责：SettingsSchema/SettingsCodec/SettingsStore/SettingsPanel；EditBoundaryPolicy（纯计算）；EditorCommands（source 事务及只读守卫）；DOMSelectionAdapter（平台映射）；Projection/Motion（无正文写权）。不是强制框架，也不建立插件架构。键盘、beforeinput、触摸选区、按钮和菜单必须汇聚到同一命令/边界服务，否则“同单位”只是表面选项。

验收分层：机器矩阵是期望而非 PASS；纯模型验证单位/配置事务，受控宿主验证事件及旧异步归属，真实浏览器验证 pointer/Range、键盘默认行为、剪贴板、焦点、触屏与中文 IME。不得拿模拟 DOM 或测试数量宣称真实设备通过。0.1.6 回退、Unicode 附着修饰符资格、选区拆合保守范围与现有项目兼容都必须回归。

设计约束：独立变化轴、单一配置源、宿主隔离、过期事务与副作用权限。该规格为设计输入，不代表实现或真人接管验证。

## 8. 新产品原则：全功能纯键盘与每轮文档维护

用户本轮明确提出：速度、简明、极致交互与动效产品的所有功能都应可纯键盘完成。这是产品级约束，不等同于“每个功能都绑定一个全局热键”。可选拆合快捷键关闭后，所有功能仍有 Tab/Shift+Tab 可达的语义控件。无 hover-only 操作，不能把触摸或鼠标作为唯一完整路径。

完整路径见 keyboard-paths.json：覆盖插入 IDC/示例、正文编辑/选择/剪贴板/撤销重做、拆合、视图与单位、设置搜索及所有值、设置与项目原生文件 picker、导出、草稿恢复、结构树/源码定位、两种 SVG 导出、动效诊断/演示、文档阅读/下载、面板开关与焦点返回。打开文件 picker 后，必须真实验证键盘选择文件、确认、取消；不能用测试框架 setInputFiles 证明用户纯键盘成功。下载需要检查原生浏览器下载/保存 UI 的键盘可用性；系统选择框属宿主能力，分别标注平台验证范围。

语义优先使用原生 button/input/select/details/dialog：按钮 Enter/Space；select 用原生箭头/确认；checkbox Space；details Enter/Space。面板 Escape 关闭并返回启动控件，设置搜索非空时先清空搜索，下一次 Escape 才关闭；焦点陷阱仅用于真模态，非模态不锁 Tab。文件 picker 的 Escape 先由操作系统消费，取消后回触发按钮，不重置正文。原生控件键行为不硬套自制列表；树如果不实现 ARIA tree 全套箭头，使用普通嵌套按钮与 Tab，禁止只写 role=tree 冒充实现。

编辑器内左右及 Shift 与本规格单位一致；Home/End、词导航、Ctrl/Cmd+A/C/X/V/Z/Y、输入法候选键与 OS/浏览器快捷键不被跨上下文抢占。应用内视图选择用可聚焦 select/按钮即可，不复用 Ctrl/Cmd+E 等浏览器既有组合。快捷键配置仅提供已审计的局部拆合方案，不暗中注册更多全局组合。
